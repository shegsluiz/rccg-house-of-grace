## 2024-05-18 - Passing aria-hidden to Custom SVGs & Dynamic aria-expanded
**Learning:** Custom SVGs (like the TikTok icon) that serve as icons within links or buttons must explicitly define and pass accessibility props like `aria-hidden` to their underlying `<svg>` tags. Otherwise, applying `aria-hidden="true"` to the component when used will result in a TypeScript error or fail to render the attribute correctly, leading to screen reader confusion. Additionally, using dynamic `aria-expanded` attributes on toggle buttons (like the mobile menu) significantly improves clarity for screen reader users by indicating the current state of the menu.
**Action:** Always ensure custom icon components accept a standard set of accessibility props (or at minimum `aria-hidden`) and pass them down. For any toggle button, pair an explicit `aria-label` with a dynamic `aria-expanded` attribute.

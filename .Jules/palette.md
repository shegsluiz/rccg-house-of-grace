## 2026-05-21 - [Accessibility of Icon-Only Controls]
**Learning:** Decorative SVGs inside interactive elements like buttons or links without `aria-hidden="true"` can cause screen readers to announce confusing graphic semantics. Adding focus states (`focus-visible:ring-2`, `focus-visible:ring-hog-green-400`, `focus:outline-none`) and descriptive `aria-label`s greatly improves the accessibility for keyboard users and screen readers navigating mobile menus or footer link icons.
**Action:** Always ensure that icon-only interactive controls contain specific `aria-label` attributes, set `aria-hidden="true"` on the underlying SVG or icon component, and style explicit `focus-visible` states to support keyboard navigation. When modifying social external links, prioritize updating `rel="noreferrer"` to `rel="noopener noreferrer"`.

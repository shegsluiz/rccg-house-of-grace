## 2025-03-05 - Enhance interactive element accessibility
**Learning:** Icon-only buttons and social media links require explicit focus states and ARIA labels. Adding `aria-hidden="true"` to SVGs ensures correct semantics for screen readers. External links should include `rel="noopener noreferrer"`.
**Action:** Always include focus styles, ARIA labels, and standard accessibility attributes on newly added interactive UI components in this application.

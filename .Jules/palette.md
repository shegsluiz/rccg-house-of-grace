## 2026-07-31 - Accessible Icon-Only Controls\n**Learning:** Custom SVG icons like the `TikTokIcon` must be designed to accept standard SVG props (such as `aria-hidden`) to be fully integrated with accessible icon-only interactive elements. Additionally, dynamic navigation toggles frequently miss `aria-expanded` and clear focus indicators.\n**Action:** Always type custom SVG icons with `React.SVGProps<SVGSVGElement>` to pass down accessibility attributes, and explicitly add `aria-expanded` / `aria-label` / `focus-visible` styles to all navigation toggle buttons.

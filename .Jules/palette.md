## 2024-08-01 - Interactive Element Accessibility Enhancements
**Learning:** Custom SVGs built as functional components (like `TikTokIcon`) often forget to type and spread props (`React.SVGProps<SVGSVGElement>`), meaning vital accessibility attributes like `aria-hidden="true"` get swallowed and ignored by screen readers, resulting in confusing icon announcements inside buttons or links. Additionally, interactive toggle elements require dynamic `aria-expanded` attributes for correct state announcement.
**Action:** Always ensure custom SVG components accept and spread standard SVG attributes. For icon-only interactive elements, ensure the container has a descriptive `aria-label`, visible focus states (`focus-visible:ring-2`), dynamic state attributes if it's a toggle (`aria-expanded`), and that inner decorative SVGs explicitly receive `aria-hidden="true"`.

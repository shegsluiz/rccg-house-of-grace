## 2025-07-30 - Interactive Elements and Accessibility Consistency
**Learning:** We identified a pattern where custom SVG components used in interactive elements lacked standard attributes, and icon-only links lacked proper labels and focus states. This diminishes the accessibility and usability for screen readers and keyboard users. Additionally, `target="_blank"` missing `noopener` attributes present security/performance concerns.
**Action:** Ensure all interactive custom SVG components accept and pass standard accessibility props (like `aria-hidden`) down to the `<svg>` tag. Consistently apply `aria-expanded` to toggle buttons, provide descriptive `aria-label`s for icon-only elements, include `focus-visible` states for keyboard navigation, and always use `rel="noopener noreferrer"` with `target="_blank"` anchors.

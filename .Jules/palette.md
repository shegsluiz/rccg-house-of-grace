## 2024-08-11 - Add ARIA Labels and Keyboard Navigation Rings to Icon Links
**Learning:** Custom SVG icons embedded within anchor tags or buttons without distinct text can be highly confusing for screen reader users unless an `aria-label` is applied directly to the parent interactive element. Also, passing `aria-hidden="true"` to these inner custom SVGs prevents redundant generic semantic announcements. Keyboard navigation lacks clarity without explicitly defined visual focus states, especially on custom styled interfaces with dark themes.
**Action:** Consistently type SVG props for custom components (like `TikTokIcon`) to accept `aria-hidden` and pass it down. Ensure all interactive icon-only elements feature explicit `aria-label`s, `focus-visible` styling using our theme colors (`focus-visible:ring-hog-green-400`), and semantic definitions. Always explicitly mark dynamically toggled elements with `aria-expanded` attributes.
